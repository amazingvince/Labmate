# Labmate Cockpit

The human's mission control for the Labmate evidence ledger. A glass-cockpit SPA
(React + Vite + TypeScript) built entirely against the OpenAPI contract in
`apps/api-spec/openapi.yaml` — first the Prism mock, then the real Worker, with a
one-line env change.

## Four-pane mission control

- **§01 Brief + rubric** — objective, target, metric + rationale, budget, derived
  guardrails, and a definition-of-done checklist (live readiness, or the
  authoritative `GradeResult` once you press *Check done*).
- **§02 Data contract** — row count, split strategy, and the column table; each
  leakage-flagged column carries a `[BAN]` action → `POST /api/feedback` (`ban_feature`).
- **§03 Experiment cards** — one per hypothesis with the latest run's metric and a
  Approve / Deny / Rerun segmented control. Approve → `POST /api/approvals/request`
  + `POST /api/feedback` (`approval`); Deny → `POST /api/feedback` (`note`);
  Rerun → `POST /api/approvals/request`.
- **§04 Evidence ledger** — runs + critiques + decisions + feedback in one feed,
  with a red alert pin when the agent catches leakage / test-set tuning.
- **§05 Run table** — status, metrics, seed, tags, linked critique badges.
- **§06 Recommendation dock** — the agent's current call + *Generate report*
  (`POST /api/reports`, surfaces the artifact link) and *Check done* (`POST /api/grade`).
- **Feedback box** — natural language → `POST /api/feedback`, with a live preview
  of the parsed constraints.

Every pane has loading, empty, and error states; approve/deny/ban are optimistic
(held in a client overlay so they stay stable even against a static mock).

## Run it

```bash
# 1. from the repo root, start the mock the cockpit talks to:
npm run spec:mock                 # Prism on http://localhost:4010

# 2. in this directory:
cd apps/cockpit
cp .env.example .env              # VITE_API_BASE + VITE_API_TOKEN
npm install
npm run dev                       # http://localhost:5173
npm run build                     # tsc -b && vite build  (must be clean)
```

## Swap the mock for the real Worker

Change one line in `.env` — no code change:

```bash
VITE_API_BASE=http://127.0.0.1:8787        # wrangler dev
# or
VITE_API_BASE=https://labmate.<sub>.workers.dev
```

## Contract is the source of truth

Types are imported from `packages/api-types` (generated by `npm run spec:types`)
via the `@labmate/api-types` alias — never hand-written. If a pane needs a field
the spec lacks, the spec changes first. Known gaps surfaced during the build:

- `Study` has no `constraints`/guardrails field → guardrails are **derived** from
  `feedback.parsed_constraints` + flagged leakage columns.
- No entity carries a timestamp → the ledger is ordered by event type then array
  sequence, not by clock. A `created_at` on runs/critiques/decisions/feedback
  would let it sort true-chronologically.
